## Olá!

### Este é um bot para realizar buscas no bing, com o intuito de ganhar pontos Microsoft Rewards ao realizar 30 buscas diárias pelo buscador da Microsoft.

### Rode o bot com: node index.js
### Use os comandos abaixos para abrir alguns navegadores no modo desenvolvedor, antes de rodar o bot:

#### google-chrome --remote-debugging-port=9222
#### microsoft-edge --remote-debugging-port=9222
#### opera --remote-debugging-port=9222

### Primeiro abra o navegador em modo desenvolvedor pelo terminal e em seguida, rode o bot para prosseguir as buscas.
